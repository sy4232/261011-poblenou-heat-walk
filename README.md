# Poblenou heat walk (prototype)

Browser viewer of a microclimate simulation of the Poblenou superblock, Barcelona, on a clear summer day.
Open `index.html` (GitHub Pages serves it at the repository URL). Runs fully in the browser; no server code.

This is a prototype for discussion. It shows a 2026-10 simulation of 30 July 2026 with the existing street trees; the scenarios without trees and with reflective roads are still being computed. The earlier version is published in Yamada et al. 2026, Street Art & Urban Creativity 12(5), https://doi.org/10.66838/sauc.6427.

Data sources: aerial photo (c) Institut Cartografic i Geologic de Catalunya (ICGC); street trees: Ajuntament de Barcelona, Open Data BCN; building footprints: Direccion General del Catastro; weather forcing: Meteocat.
